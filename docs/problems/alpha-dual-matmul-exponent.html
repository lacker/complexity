Statement

Let omega(1, k, 1) be the exponent of multiplying an n x n^k matrix by an n^k x n matrix, and define alpha as the largest k with omega(1, k, 1) = 2 — the widest aspect ratio at which rectangular matrix multiplication is essentially free. Trivially alpha <= 1, and alpha = 1 if and only if omega = 2. The problem: publish any bound alpha > 1/2, or settle the claimed upper bound alpha <= 2/3 (and the Lean claim alpha = 1/2, below) by refereeing or refuting it.

Current record

The record is now alpha >= 1/2, well above the laser-method value 0.321334 (Vassilevska Williams, Xu, Xu and Zhou, SODA 2024, arXiv:2307.07970).

  • The bound: Uznański (arXiv:2610.10494) extends OpenAI's October 2026 matrix multiplication analysis to rectangular products and states alpha >= 1/2. Amanov, van den Berg and Zuiddam (arXiv:2610.30054) state omega_F(1,k,1) = 2 for 0 <= k <= 1/2 over every field.
  • The other side, claimed: OpenAI's 24 Nov 2026 preprint (not refereed) claims 1/2 <= alpha <= 2/3 over every field (Corollary 1.3), which would be the first upper bound below the trivial alpha <= 1.
  • Its Lean release goes further: it proves alpha = 1/2 exactly, with a closed formula for rectangular exponents.
    • Model: the Comparator challenge states alpha for division-free programs. The proof runs through a rectangular model with division gates, with the small dimension inner, as in this entry (MatrixExponent.Rectangle.dual_square).
    • Independent audit: Toledo (carlostoledo.co/omega) reports the challenge certified. He reports the with-division alpha = 1/2 as passing in a later phase, outside the verdict.
    • Statement audit: a statement audit by the author of this change compares the Lean with the paper. It did not build the Lean.
  • Not covered: no human refereeing yet. If correct, alpha = 1/2 resolves this entry, and beating 1/2 would contradict a machine-checked theorem.

Why it matters

Alpha is a load-bearing dual of omega: many graph algorithms are bottlenecked by unbalanced products rather than square ones. Zwick's APSP for directed unweighted graphs, dynamic transitive closure and dynamic reachability (the n^{1.407} bound in the dynamic-transitive-closure-omv-hardness entry explicitly trades off against omega(1, k, 1)), all-pairs bottleneck paths, sparse matrix multiplication, and interior-point LP solvers all inherit exponents from the rectangular tables. An improved alpha propagates through these automatically, and since alpha = 1 is equivalent to omega = 2, alpha progress is omega progress measured along a different axis — sometimes an easier one, since rectangular analyses have more slack to exploit.

Attack surface

The laser-method experiments that set the old record (0.321334) cannot reach the new one, and the rectangular barriers of Christandl, Le Gall, Lysikov and Zuiddam cap that family. The live work is verification: referee the claimed upper bound alpha <= 2/3 in the November 2026 preprint, or check its Lean proof of alpha = 1/2 (MatrixExponent.Rectangle.dual_square), whose rectangular model allows division and puts the small dimension inside, as in this entry. A human-readable proof of alpha = 1/2 matching the Lean would also be new.
